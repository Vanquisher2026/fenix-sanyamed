## 1. Обработка звука (whisper.cpp + FFmpeg)

### Транскрибация на русском (Whisper large-v3)
```bash
# Установить whisper.cpp
brew install whisper-cpp   # или скачать бинарь

# Прогнать каждое видео
for f in raw/*.mp4; do
  ffmpeg -i "$f" -ar 16000 -ac 1 -c:a pcm_s16le "${f%.mp4}.wav"
  whisper-cli -m ggml-large-v3.bin -l ru -f "${f%.mp4}.wav" \
    --output-srt --output-json --output-file "${f%.mp4}"
done
```

### Чистка аудио (если гул/ветер)
```bash
# RNNoise (нейросетевой шумодав)
ffmpeg -i raw/03-konsultaciya.wav -af "arnndn=m=model.rnnn" \
  -c:a pcm_s16le clean/03.wav

# Нормализация громкости
ffmpeg -i clean/03.wav -af "loudnorm=I=-16:TP=-1.5:LRA=11" \
  clean/03-loud.wav
```

### Результат
`raw/*.srt` — русские субтитры с таймкодами
`raw/*.json` — текст + сегменты для AI-анализа

## 2. Сборка скрипта (AI-монтаж на LLM)

### Скрин-промпт
```
Склей из 10 фрагментов субтитров из разных сцен.
Удали: паузы, слова-паразиты, повторы, неудачные дубли.
Сохрани: ёмкие цитаты, цифры, ключевые факты.
Целевой хронометраж: 8 минут (≈ 1100 слов).
Структура: Прилёт → Заселение → Диагностика → Процедуры → Результат → Итог.
Тон: спокойный, искренний, как обычный разговор.
```

### Ручная доработка скрипта
- Выкинуть всё, что не попадает в структуру 8 сцен
- Подтянуть хронометраж — длинное в первые 30 сек, драматичное — в конец
- Добавить **CTA** в финал: «Если интересно — оставьте заявку,
  ссылка в описании»

## 3. Монтаж (CapCut / DaVinci Resolve)

### Выбор инструмента
- **CapCut Desktop** (бесплатно, AI-субтитры, шаблоны) — для 80% задач
- **DaVinci Resolve** (бесплатно, профессиональный) — если хочется цветокор

### Пайплайн CapCut
1. Импортировать `raw/*.mp4` в таймлайн
2. Нарезать по сценам из скрипта (см. шаг 2)
3. Субтитры: «Текст → Автоматические субтитры → Русский»
   - Стиль: белый текст, чёрная обводка 2px, шрифт Inter
   - Размер: средний (читается и на 6" экране, и на 50" телевизоре)
4. Музыка: **без авторских прав**:
   - Pixabay Music (поиск «calm», «hope», «inspiration»)
   - YouTube Audio Library (фильтр «Attribution not required»)
   - Громкость: −18 dB относительно голоса
5. Intro-карта (3 сек): «Санаторий ТАЙЦЗИ • Са́нья, Хайнань»
   - Угловой логотип + название
6. Outro (10 сек): «Записаться → wa.me/8613158954278»

### Переходы
- **jump cut** между фрагментами одного сюжета (не jump cut каждые 2 сек)
- **dissolve 0.5 сек** между сценами
- Никаких «звёздочек», «сердечек», «смайликов» — это отталкивает русскую
  взрослую аудиторию (45+)

### Цветокор
- Лёгкий teal-orange grade (типичный «travel video»)
- −5 яркость, +5 контраст в Resolve / CapCut
- В стабилизаторе (CapCut) включить для трясущихся телефонных кадров

## 4. Генерация превью (Canva / Photoshop AI)

### 3 варианта превью
1. **Лицо гостя крупно (60% кадра) + локация на фоне**
2. **Крупный план игл / массажа + «8 минут правды» (русский текст)**
3. **Коллаж: гость + врач + 3 фото процедур**

### Текст на превью (русский, 3–4 слова)
Варианты (выбрать по силе эмоции):
- «САНЬЯ: МОЯ ПРАВДА»
- «6 ПРОЦЕДУР ЗА НЕДЕЛЮ»
- «12 000 ¥ ЗА ВСЁ»
- «ПОЧЕМУ Я ВЕРНУСЬ»
- «НЕ ПОКУПАЙ ДО ЭТОГО»

### Технически
- 1280×720 для YouTube / Zen
- 1080×1920 для Shorts / Клипов
- 600×600 для Telegram preview
- Шрифт: **Inter Bold** (хорошо читается на миниатюре)
- Цвет текста: жёлтый с чёрной обводкой (высокий CTR)
