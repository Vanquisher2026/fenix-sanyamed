1. 打开 `metrika.yandex.com` → 用 Yandex ID 登录

   - **Часовой пояс（时区）**：UTC+8（北京时间）
   - **Вебвизор（会话回放）**：✅ 开
   - **Карта кликов（点击热图）**：✅ 开

4. 系统生成 **counter ID（形如 `XXXXXXXX`，8 位数字）**——这是要发给开发者的唯一信息

#### C. Webmaster 接入流程（10 分钟）

**C1. 添加并验证域名**

1. 打开 `webmaster.yandex.com` → 用同一 Yandex ID 登录
2. 点击「Добавить сайт」→ 填 `https://taiji-hainan.ru`（**带 https://**，与 Metrika 不同）
3. **验证方式选择**——按可靠性降序：

| 验证方式 | 实操 | 适用 | 备注 |
|---|---|---|---|
| **DNS-запись（TXT）** | 在域名 DNS 加 `yandex-verification: 0xxxx...` 的 TXT 记录 | Cloudflare 用户 / 域名所有者 | ✅ 最稳，不依赖服务器 |
| **HTML-файл** | 上传 `yandex_xxxxxxxxxxxxxxx.html` 到网站根目录 | 能 SSH / FTP 上传者 | ✅ 简单，1 分钟搞定 |
| **Мета-тег** | 在 `<head>` 加 `<meta name="yandex-verification" content="0xxxx...">` | 不能改 DNS 的人 | ✅ Next.js 里直接写 |
| **WHOIS** | Yandex 自动读 WHOIS 库 | 域名是您本人注册 | ⚠️ 不一定生效 |

**推荐**：您用 Cloudflare 管 DNS → DNS TXT 验证；否则 → Meta 标签（我可以代写进 `layout.tsx`）。

**C2. 设置地域归属（**关键**，否则俄客搜不到你）**

- **Регион сайта**：`Китай, провинция Хайнань`（注册地区）
- **再勾选「Сделать регион сайта равным региону, указанному в Яндекс Справочнике」** —— 让 Maps 商家卡片和 Webmaster 地区对齐
